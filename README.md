## 三网优化优在哪，哪些“三网优化”标签是需要警惕的

“三网”指电信、联通、移动三家。理想状态下，一台机器回国要让三家各走各的精品网：

- 电信走 **CN2 GIA（AS4809）**，电信自营的精品网，绕路少，晚高峰比普通 163 线路稳；
- 联通走 **CUII / AS9929**，联通的 A 网商务线路，比普通 AS4837 强一档；
- 移动走 **CMIN2（AS58807）**，移动自建的国际传输网，补的是移动过去国际出口的短板。

只做双程 CN2 GIA 的机器，电信用户体验很好，联通和移动用户晚高峰照样可能绕路。三家都照顾到，带宽成本摆在那里，所以正宗三网优化的机器普遍更贵。

问题在于“三网优化”没有统一标准。次一档的 CN2 GT、联通 AS4837、普通 CMI，也常被商家算进这个词里。同一个商家不同系列档次都能不一样：HostDare 的 CSSD 系列官方标注是 CN2 GIA + AS4837 + CMI，联通走 AS4837、移动走普通 CMI；CAMD 系列才标注 CN2 GIA + CUII + CMIN2，同价位流量还翻倍。所以看路由要落到具体系列，不能只看商家的招牌。做汇总的星空VPS 也写明了，页面上的线路标签“沿用商家标称”，不是实测结果。

Akile 在这件事上更需要注意。它的命名里，Pro 比同机房 Lite 贵、端口小、流量少，按常识会以为 Pro 是线路更好的那一档。较早的产品页确实把洛杉矶 Pro / Premium 标成“电信回程 CN2 GIA、联通回程 9929、移动回程 CMIN2”，还带单 IP 20Gbps 的 DDoS 防御。但公开的套餐说明并没有写清楚每个型号分别走哪种路由，日本系列只笼统写了“包含直连和路由调优型号”，哪个型号是哪种没列。

这意味着两件事。第一，想要三网优化回程，必须在下单页的线路字段里逐个核对，别默认 Pro 就一定优化、Lite 就一定不优化。第二，如果你只是要一个大带宽、能解锁流媒体、能跑中转的海外机器，Lite 系列的性价比明显更高：¥15.99/月给 2GB 内存、2TB 流量、5Gbps 端口，比 ¥43.74/月只给 300GB 流量的 Pro-Light 宽裕得多。

## 常见问题

**晚高峰会不会掉速？**
三网优化解决的是绕路和共享普通线路的拥堵，不解决超售。三家各走精品网，丢包和延迟波动会比普通国际线路小，但具体表现取决于机房带宽和这台母机上放了多少人。买之前 ping，买之后头几天在 20:00–23:00 测一轮，不满意趁早处理。

**年付还是月付？**
Akile 的低价标价基本都是年付摊薄，月付单价更高。洛杉矶 Lite 系列月付门槛低，可以先月付跑一个月再决定要不要年付。香港、日本的大流量档月付金额高，年付前更该先试。

**1GB 内存能建站吗？**
静态站、单页、轻量博客可以。WordPress 加几个插件就会吃紧，数据库和应用一起跑更容易出问题。建站按 2GB 起步，这个门槛在 Akile 和别家都一样。

**洛杉矶 Lite 的 5Gbps 端口是真的吗？**
端口速率是商家标称的规格，实际能跑多少取决于你的本地带宽、国际出口和对面服务器。5Gbps 是上限，不是承诺值。国内单线程下载通常跑不到这个量级，多线程和大文件分发才用得上。

**香港和日本比洛杉矶快多少？**
物理距离摆在那里，香港、日本节点到国内的延迟通常低于美西。美西机房国内延迟普遍在 130–175ms 这个量级，要明显更低就得靠近，价格也跟着上去。做站还是做中转，先想清楚是延迟重要还是流量和端口重要。
